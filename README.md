# Ster Books

## 概要
Figmaデザインカンプをもとにコーディングした
架空のブックカフェのLP。
SCSS/BEM記法を実装しています。

## 使用技術
* HTML
* SCSS（BEM記法 / ファイル分割 / mixin / CSS変数）
* JavaScript（Vanilla JS）
* Figma（デザインカンプをもとに実装）
* モバイルファースト設計
  
## こだわったポイント
* 保守性を意識したSCSSファイル分割
　（他のメンバーが更新しやすい構成を意識）
* モバイルファーストでスタイルを構築し、
　メディアクエリで段階的に拡張
* セマンティックなHTMLで構造の分かりやすさを重視
* aria-expanded / aria-controlsを使った
　アクセシビリティへの配慮（ハンバーガーメニュー・アコーディオン）
* Intersection Observerを使ったスクロール連動の
　フェードインアニメーション
